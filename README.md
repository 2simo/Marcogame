#🐺 MARCO RX6

Your official destination for Blog, Tech & Gaming.

MARCO RX6 is an Android application that provides easy access to the MARCO RX6 blog.

✨ Features

- 🌐 Browse the MARCO RX6 blog.
- 📴 Offline reading for saved posts.
- 🖼️ Offline access to downloaded post images.
- 🔔 Notifications for new posts.
- ⚡ Fast and simple browsing experience.
- 🐺 Custom wolf-themed splash screen.
- 🖤 Modern black and purple design.

🌍 Official Blog

https://marcorx6.blogspot.com

📱 Requirements

- Android 6.0 or later.
- Internet connection for online browsing and synchronization.

📥 Download

Download the latest APK from the "Releases" (../../releases) section.

- Android SDK
- Android WebView
